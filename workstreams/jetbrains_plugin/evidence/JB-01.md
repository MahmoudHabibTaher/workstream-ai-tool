## Proposed decisions

### P1: `launches` is required on every row, and `snapshotVersion` stays 1
Every row the snapshot builds carries `launches` (empty when closed), so the schema requires it, as it does `actions`; the field is additive, as `actions` and `refresh` were without a version bump. Rejected: optional `launches`, which would let a consumer meet a row without it; bumping to 2.

### P2: the prompt is filled with the row's id in the snapshot
`prompt` holds the finished text (`{ws}` already replaced), so the plugin copies nothing and formats nothing. Rejected: a template with `{ws}` for the UI to fill.
