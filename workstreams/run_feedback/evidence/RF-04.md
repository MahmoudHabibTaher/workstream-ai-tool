## Proposed decisions

### P1: only a line with a leading pipe is a table row, and the first cell is read literally
`find_section` skips rows inside code fences, and doesn't read `G7 | text` (no leading pipe) or `| **G7** | text |` (bold) as G7. D-CITE says the first cell starts with the ref, and a loose match could turn prose into a citation. Those forms still get the warning, so nothing is hidden. Rejected: stripping emphasis markup and accepting pipeless rows.

### P2: a blank PLAN.md counts as not written
`citation_warning` skips an empty or whitespace-only `PLAN.md` as it does a placeholder one, since it has nothing to cite yet. Rejected: warning about every ref in a file that has no plan in it.
