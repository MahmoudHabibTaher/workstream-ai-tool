# AD-04 evidence

- **Status:** done

## Acceptance

1. doctor passes on a good repo and writes nothing -> `GoodRepoTests.test_a_good_repo_passes` and `test_it_writes_nothing` pass, the second comparing every file's bytes before and after, with `--run` too
2. it fails on a broken config, a missing integration branch and an invalid queue -> `FailureTests` passes: an unparseable config, an unknown section, a missing integration branch, an invalid queue and a broken registry, none with a traceback
3. it warns on a missing tool, an uncommitted config and a stray adequacy key -> `WarningTests` passes for a missing tool, an uncommitted config and stray `[adequacy]` and `[baseline]` keys
4. --run fails on a new finding and passes on known ones -> `RunTests.test_a_new_finding_fails` and `test_known_findings_pass` pass
5. it works outside a project and says to run init -> `OutsideAProjectTests` passes: `no .workstream/config.toml: run \`ws init\``. On this repo `ws doctor` printed OK with one warning, for standing on a task branch

## Proposed decisions

### D006: a warning never changes doctor's exit code
A missing tool may be fine on this machine and needed on another, and scripts need a clear signal for what is really broken. Rejected: a strict flag, since nothing needs it yet.

## Gotchas and follow-ups

An identity set only in environment variables counts as known, because that is how CI and tests commit.
