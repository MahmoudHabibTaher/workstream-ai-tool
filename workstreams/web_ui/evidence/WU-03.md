# WU-03 evidence

- **Status:** done

## Acceptance

1. the assets ship as package data, and a test holds that nothing refers to another host -> `pyproject.toml` lists `assets/web/*`; tests/test_web.py `test_the_files_are_package_data` and `test_nothing_is_fetched_from_another_host`. WU-06 proves the wheel.
2. no asset uses innerHTML or eval, and a test holds that -> `test_no_script_can_parse_a_string_as_markup_or_code`. In the browser on a sample project, a title of `Multiply <img src=x onerror=alert(1)>` and a summary with a script tag drew as text, with no console errors.
3. the literals test covers the web assets -> tests/test_no_project_literals.py scans `.js`, `.css` and `.html`, and `test_finds_the_core_files` asserts it found a `.js`.
4. the pure helpers have tests that run where Node exists and skip where it doesn't -> `ui/web/tests/*.test.mjs`, run by `PageLogicTests`, which is `skipUnless(shutil.which("node"))`. They passed here on Node 26.

## Proposed decisions

### D006: the confirm box keeps the revisions from when it opened
With live updates, the latest snapshot would pass the guard for something the person never saw. So the box pins them, and warns if they've moved. Rejected: taking them at click time from the newest snapshot, which turns the guard off.

### D007: copying a prompt stands in for filling a prompt box
A browser has no prompt box to fill. Copying leaves the send to the person, as the pane does. Rejected: launching an agent, which the plan rules out for a standalone page.
