The sample's `workstreams.agentCommand` was `["/bin/sh", "-c", "printf ... \"$0\"; exec /bin/zsh -i"]`, which shows the argument it got, instead of `claude`, so the check didn't start a real agent on the sample. `/bin/echo` was tried first and exited before the terminal drew anything. 0017 lists a real agent under Not proven.
