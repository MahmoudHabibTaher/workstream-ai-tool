## Proposed decisions

### D008: the task page replaces the inline expansion in Tasks
A task row now opens `screen: 'task'`, which shows everything the expansion did (summary, acceptance, verify, files, notes, requires, Review, Unclaim) plus depends on, unblocks and the claim. The expansion was removed from `detail.tsx`, so there is one view of a task, not two. The Graph's line (D005) now opens the page too. Rejected: keeping both, which would mean two copies of the same task view to keep in step.

### D009: Back from a task page goes to detail, and Back from Review goes to the task page
Jumping between tasks keeps no history: Back always returns to the sub-screen the person was on. Review is reached only from a task page now, so its Back returns there. Rejected: a jump history stack, which is more state for little gain.
