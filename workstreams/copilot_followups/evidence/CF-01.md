## Proposed decisions

### P1: Copilot's figure is found at any depth, and the fallback session is the newest one written since the run started
Real events put `totalNanoAiu` on `data` or on `data.accountingSnapshot`, and the `--output-format json` stdout shape wasn't recorded, so `cost_from` takes the last `totalNanoAiu` at any depth in the log, then in the newest `events.jsonl` whose mtime is at or after the run's start. `cost_from` takes optional `sessions` and `since` keywords beside `(log, agent)` so tests don't touch `~/.copilot`. Claude's lookup stays top-level `total_cost_usd`, as before. Rejected: hard-coding the two paths found so far, which a third shape (the stdout `result` line) would miss; and taking the newest session regardless of time, which would report a previous run's credits when this run wrote none.

### P2: the existing Claude cost test changed its expected value to `(0.2, "USD")`
D-CREDITS makes `cost_from` return `(amount, unit)`, so the old `assertEqual(..., 0.2)` couldn't pass unchanged. The test's log and intent are the same. Rejected: keeping a float-returning `cost_from` for Claude, which contradicts D-CREDITS.

## Gotchas and follow-ups

- Copilot's `task` tool may write sub-sessions to their own `events.jsonl`. The fallback takes only the newest one, so a run whose log has no figure could under-report. Not seen yet; CF-05's real run would show it.
