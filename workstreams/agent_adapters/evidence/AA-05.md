## Proposed decisions

### P1: Workers commit through `ws commit`, not git
A background worker's shell doesn't stay in its worktree and it can't ask for approval, so git aimed at the worktree is denied. The command also refuses tracking files and leaves out worktree setup's output. Rejected: allowing `git -C *`, which would allow a push too.

### P2: `ws update --status done` refuses a commit that hasn't landed
A real worker used it to mark its own task done. Hand merges still work, since their commit is on the integration branch. Rejected: relying on the protocol's wording, which held in one run and not the next.

### P3: Evals default to Opus 5.5 on medium effort, with a Copilot cap of 80
The user's preference, and a cap the agent can see changes its behaviour. Rejected: Sonnet to fit a tighter cap.
