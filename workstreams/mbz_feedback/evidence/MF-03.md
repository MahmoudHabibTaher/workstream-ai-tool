## Proposed decisions

### D004: Text naming a path the evidence check rejects is left out of `to apply:`, unread

The settle gate already refuses such evidence, so this only reaches evidence that skipped the gate. Telling a coordinator to apply text outside the project would be worse than saying nothing. Rejected: listing it unread as not applied, which sends the coordinator to write outside the repo.

### D005: The close warning reads `warning: to apply: <line>`

It keeps the prefix settle prints, so the same search finds both. Rejected: separate wording for close, which says nothing more.
