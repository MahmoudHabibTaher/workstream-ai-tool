## Proposed decisions

### D002: Text to apply is shielded from the rest of the evidence handling
Everything before the section is what parse, the placeholder check and `rewrite_ids` work on. Otherwise a `## Acceptance` in the text would overwrite the real section in `_sections`, a double-brace template in the text would fail the check as an unfilled placeholder, and settling would rewrite a `D002` in the text, so it would no longer be exact. Rejected: leaving the placeholder check and `rewrite_ids` reading the whole file, which is less code but breaks the exactness D-TEXT asks for.

### D003: The first `## Text to apply` heading at the start of a line opens the section
The text under it may quote the heading, as text about this very section would. Rejected: the last such heading, which would cut that text short. The cost is that an earlier section can't hold the heading at the start of a line, which would already split it in `_sections`.
