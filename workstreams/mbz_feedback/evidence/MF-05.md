## Proposed decisions

### P1: A correction whose new text ends in a mark merges that mark rather than doubling it

A coordinator may paste the old text back with an edit, so `--summary "new (changed by D001)" --because D002` writes `new (changed by D001, D002)`, and text that is only a mark is refused as empty. Rejected: treating the pasted mark as plain text, which writes two marks in a row.

### P2: The warning reads the marks anywhere in the summary and acceptance, while a merge reads only the mark at the end

The warning asks whether a decision has been applied at all, and the task's text is the only record of that. Rejected: counting only a trailing mark for the warning, which would warn about a correction a coordinator reworded by hand.
